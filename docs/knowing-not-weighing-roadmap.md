# Knowing Is Not Weighing：LLM 审稿人"检测—加权—怀疑"因果审计 · 研究路线

状态：2026-10-25 立项草案；尚未跑实验；未公开预注册。

## 1. 核心主张与度量
主张：LLM 审稿人的三个通道（**检测** D：是否指出问题；**加权** W：分数/决策变化是否与严重度相称；**怀疑** U：缺信息时是否降低置信度/弃权）可被因果地解耦，且通常不一致——"知道"不等于"称重"，"不知道"也不等于"怀疑"。
- D：审稿文本中是否定位到注入问题（LLM 判官 + 人工抽检 10%，κ≥0.7 方可用）。
- W：Δscore（相对中性改写）与预登记严重度的比；**门限违规**＝检测到致命缺陷但总体分仍 ≥ 接收线。
- U：按维度置信度、"无法评估"勾选、对冲词密度、3 次采样的分数方差；**无据断言**＝删除信息后仍断言具体缺陷/正确性。

## 2. 理想响应剖面（预登记）
| 版本 | D | W（相对 N） | U（soundness 置信度） |
|---|---|---|---|
| O 原文 / N 中性改写（编辑量匹配） | 无新问题 | 0 | 不变 |
| P 仅润色 | 无 | ≈0（呈现分可小升） | 不变 |
| F 致命缺陷 | 指出 | 大幅下降，跌破接收线 | 不变或略降 |
| F+P | 指出 | 同 F（润色不补偿） | 同 F |
| R 删除判断所需信息 | 指出"缺失" | 适度下降或弃权 | **下降**，勾"无法评估" |
| R+P | 同 R | 同 R | 同 R |

## 3. 假设
- H1：P(总体分 ≥ 接收线 | F 且检测到) > 0，且显著高于理想值 0（预设实质阈值 ≥10%）。
- H2：混合效应序数回归中 F×P 交互为正（润色补偿缺陷）。
- H3：R 相对 N 的 soundness 置信度降幅 ≈ 0（等价检验界 ±0.25 档），且无据断言率 >0。
- H4：门限违规率/传导率在"实验设计类"（泄漏、不公平基线、删实验）与"推导类"缺陷间不对称（方向不预设，双侧）。

## 4. 数据与规模
- ~80 篇 ACL Anthology 实证 NLP 论文（CC-BY 4.0，允许改编发布），优先 2026 年上半年及以后（晚于多数模型截止）；K0 只需 10 篇。
- 缺陷 4 类：数据泄漏、不公平基线、删除支撑核心结论的实验、推导/公式错误。每篇注入 1 处，两名专家独立确认"有效且致命"。
- 版本 7（O,N,P,F,F+P,R,R+P）× 80 = 560 份稿件；6 配置 × 3 采样 ≈ 1 万份审稿。
- 正文以纯文本/LaTeX 源输入（规避 PDF 解析噪声），截断上限统一 32k tokens。

## 5. 控制
- 编辑量匹配：N 与 F/R 的 token 编辑距离差 ≤10%；"改动痕迹"探针：让模型判断哪一段被改，若识别率显著高于随机，则在分析中加入"被识别"协变量。
- 润色由独立模型执行且禁止改动数字/结论（diff 自动校验）。
- 位置控制：注入位置在正文前/中/后分层。
- 人类基线：15 篇 × {F, R} 由 2–3 名领域审稿人盲审，排除"人也漏"的伪阳性。

## 6. 指标
检测率；传导率（Δscore|检测 / 严重度）；门限违规率；交互项 β_{F×P}（序数 logit，随机效应：论文、模型）；证据响应度（R 相对 N 的置信度降幅）；无据断言率；错归因比例（扣分理由指向非注入处）。所有指标给论文级 cluster bootstrap 95% CI。

## 7. 对比配置
1 直接提示；2 ARR 表单 + 按维度置信度 + "无法评估"；3 DeepReview 式结构化多步；4 多智能体（审稿人×3 + AC 汇总）；5 高推理强度（thinking/high effort）；模型：开源 Qwen3-8B/32B（本地），闭源 2 家（需预算确认）。

### 7b. 与前人工作的对比（2026-10-25 加入）
审计类论文没有"SOTA 分数"可刷，"做到 SOTA"在本路线落成两件事：
1. **把前人的审稿系统当被测对象**，在同一 7 版本矩阵上报 D/W/U：
   - DeepReviewer-7B/14B（ACL 2025，phi-4 底座，Fast/Standard/Best 三档）。HF 门控许可（需用户本人同意"不用于正式审稿"条款）；ModelScope 未上架，服务器连不上 HF → 需本机下载后 scp，14B 约 28GB。
   - CycleReviewer-8B（同组，许可同上）。
   - AI Scientist 审稿提示、2608.28626 的"核查提示"、AgentReview 式多智能体：只是提示/流程，开源模型上直接复现。
   - 预期卖点："专门训练的审稿模型在 D 上更强，W/U 却不更好"——若成立就是最强的结论。
2. **在前人基准上做对照**：在我们的稿件上复现 2608.28626 的检测率口径（表面矛盾型错误）和 PRISM 的致命/轻微维度，说明我们的 W/U 指标给出了它们给不出的排序。
3. **（G1 后视结果决定）修复方法**：若 W/U 脱节稳定存在，提出轻量修复（例如"先列缺陷→按严重度门限强制约束总分"的检测-加权耦合流程，或"按维度证据清单→无证据则弃权"），与上述所有系统比门限违规率和无据断言率——这一项可以真正"超过前人"。

## 8. 先例与新颖性边界（2026-10-25 复核）
| 工作 | 做了什么 | 与本文差异 |
|---|---|---|
| arXiv 2608.28626《Do LLMs scrutinise what they review?》（ICLR 2026 稿件，145 处注入错误，GEE 分析检测率 + 分数校准 + 作者身份） | 已精读全文（Alharbi 单作者，2026-07）。Qwen2.5-VL-72B/Pixtral-Large，约 1 万份审稿；注入的是内部矛盾型错误（数字、p 值、夸大、逻辑/趋势反转、图文不符）；因子为作者声望、有无图、自然/核查提示。检测率 12.1%，加核查提示后 22.2%；LLM 分数 7.0–8.1，远高于人类且几乎不随稿件质量变化；给图反而降检测、升分；**无图时半数审稿描述了未提供的图** | **只测 D**：分数只在干净稿上报告，没有"检测到后分数是否传导"的分析（H1 未覆盖）；无润色，无 F×P（H2 空白）；不删判断所需信息，不测置信度/弃权（H3 基本空白）。须引用并区分："描述未提供的图"是 H3 无据断言的雏形；它的错误是表面可核对的自相矛盾，我们的是需要推理的实质缺陷，H4 可直接对照 |
| PRISM（2605.26730） | 多维审稿基准，发现致命方法错误难检测 | 只测 D，不测 W/U |
| LLM-as-a-Reviewer（2605.25415） | 评分/置信度虚高、提示注入 | 观察性置信度偏差，无因果干预；我们不做注入攻击 |
| PremiseCheck / ReviewFact（2026，仅见二手报道） | 审稿意见逐条对照论文核实 | 评估审稿意见真伪，不操纵论文；可作 U 通道"无据断言"判官参考 |
| ClaimCheck（EMNLP'25 Findings） | 审稿批评的接地性 | 同上，观察性 |
| SPOT / FLAWS / LimitGen | 检测论文错误/局限 | 只测 D |
| RINoBench、Liu & Shah 2023、LLM-REVal、paper laundering、Li et al.（删方法细节） | 检测、润色偏差、删细节 | 各覆盖单一通道；无三通道联合因果剖面 |
| "Old Ideas, Novel Problems"（arXiv 2610.02022，Sternlicht…Hope，2026-10） | LLM 新颖性判官评 AI 生成想法：提示微扰可翻转过半判决，检索/推理预算帮助小 | 只评想法新颖性（我们已砍 novelty 维度），无稿件干预、无 D/W/U 解耦；可引作"判官不稳定"动机，并支持我们用 3 采样 + 多配置 |
| Liu & Zhai 2026（arXiv 2604.15145，公理化新颖性度量基准） | 对比池受控操纵，检验新颖性分数是否按公理方向变化；发现人类新颖性分与质量纠缠 | 方法论同源（"受控干预 + 预设理想响应方向"），但对象是新颖性度量且操纵比较池而非稿件；无 D/W/U。引作"公理/理想剖面"方法先例 |
结论（2026-10-25，已读 2608.28626 全文）：未发现"同一稿件矩阵上三通道联合 + 缺陷×润色交互 + 删除信息检验怀疑"的直接撞车，G0 通过。附带提示：①旧开源模型检测率很低（约 10%），K0 中"检测到"的样本可能太少，H1 条件比例不稳 → K0 用 Qwen3 新模型并选更显眼的缺陷，必要时加核查提示配置以扩大检测样本；②2608.28626 发现 LLM 分数几乎不随稿件质量变化，W 通道可能整体失灵，届时"脱节"更像"不称重"而非"打折"，叙事要能容纳这种情况。

## 9. 实现难度审计
- 注入：中等。泄漏/删实验可半自动（LLM 草拟 + 人审），推导错误需人工。每篇约 30–45 分钟专家时间。
- 抽取 D/U：LLM 判官 + 结构化 JSON 表单，难度低；风险在判官一致性。
- 统计：ordinal 混合模型（R `ordinal::clmm` 或 Python `statsmodels`/bambi），低。

## 10. 可行性审计
- 本地：ecs-bai-quad 3×A100-80GB（共享，StepKV 占用时只用空闲卡）；vLLM 跑 Qwen3-8B（1 卡）/32B（1–2 卡 bf16 或 AWQ）；模型从 ModelScope 下载到 /diskF/jiaqizhang（32B ≈ 65GB，需先查剩余空间）。
- 吞吐：32k 输入 + 2k 输出，32B 单卡 vLLM 约 30–60 份/小时；全量开源部分（560×2模型×5配置×3 ≈ 1.7 万）约 1–2 周 GPU，可行但需分批。
- 闭源：1 万份 × ~35k tokens ≈ 3.5 亿 input tokens，需按所选模型定价确认预算（可用 prompt caching 降低——同论文多配置共享前缀有限，粗估数千美元量级）。
- 人力：两名专家（注入验证）+ 人类基线审稿人，为最大瓶颈。

## 13. K0：最小决定性实验（1–3 天）
- 论文：10 篇 2026 年 ACL/EMNLP CC-BY 实证论文（有 LaTeX 源，arXiv 可取）。
- 版本：N、F（泄漏或删除核心实验，二选一，便于自动化+人工 5 分钟核验）、R（删除数据划分/评测协议段落）——3 版 × 10 = 30 稿件。
- 模型：Qwen3-8B、Qwen3-32B（AWQ），ModelScope 下载；vLLM。
- 配置：仅 ARR 表单（含按维度 1–5 置信度 + "无法评估"），温度 0.7，3 采样 → 30×2×3 = 180 份审稿，单卡约 3–6 小时。
- 判官：Qwen3-32B（另一 prompt）判 D 与无据断言，作者手审 30 份校准。
- 通过/失败（预登记）：
  - H1 信号：F 中被检测审稿里，≥10% 仍 ≥ 接收线（overall ≥3/5），且 Δscore(F−N) 平均 < 1 档。
  - H3 信号：R 相对 N 的 soundness 置信度降幅 < 0.25 档，或无据断言率 ≥20%。
  - 两者皆无 → 关闭本路线（或仅在闭源上复测一次后决定）；任一有 → 进入 G1。
- 产出脚本：`make_versions.py`（diff 校验）、`review.py`（vLLM 批推理，JSON 表单）、`judge.py`、`analyze.py`。

## K0 结果（2026-10-25，Qwen3-8B / Qwen3-32B-AWQ，ARR 表单，思考关闭）
样本：F 有效 5 篇、R 有效 5 篇（Claude 代标注，非专家），N 9 篇；每份 3 次采样，114 份审稿全部解析成功；判官 Qwen3-32B-AWQ（人工一致性尚未检验）。
- D：两模型对 F 泄漏的检测率均为 **0/15**（关键词复查 "test set/leak/contamina" 同样 0/30），N 假阳性 0。
- 分数天花板：overall 几乎全是 4–5（8B 多为 5，32B 多为 4），soundness 置信度全在 4–5，cannot_assess 从未勾选。F−N 总分差 ≈0。
- R：文字上说"信息缺失"的比例 R 0.53–0.60，但 **N 也有 0.33–0.67**（泛泛的"细节不够"），R 相对 N 无增量；soundness 置信度 R−N = 0 / −0.20。
- 预登记判定：H1 不可评估（检测数 <5）；H3 机械判为"通过"。**但这是关卡写得有漏洞**：一个对任何干预都不敏感的模型会自动满足"置信度不降"。实质结论：K0 **没有**给出"知道但不称重/不怀疑"的证据，给出的是"根本没发现 + 打分饱和"。
- 含义：在 ≤32B 开源模型上，三通道解耦无从谈起（D 通道为 0，W/U 没有可条件化的样本）。若要继续，必须先让 D>0。

### K0b（建议，1–2 天）
1. 换更强审稿人：闭源前沿模型（需预算，约 60 份审稿 × 15k tokens，成本很低）+ Qwen3-32B 开思考模式 + 2608.28626 式核查提示；DeepReviewer-7B（传输中）。
2. 修关卡：H3 改为"R 相对 N 在文字层面多指出缺失（差值 ≥0.2），而数值置信度/弃权不变"——即必须先有"知道"，才谈"不怀疑"。H1 维持需 ≥5 个检测样本。
3. 若强模型上 D 仍 ≈0：路线叙事转为"检测失败"，与 2608.28626/PRISM 高度重叠 → 关闭。

## K0b 结果（2026-10-26，Qwen3-32B-AWQ × {think, verify, think+verify}，DeepReviewer 待补）
- 判官过宽：它把核查提示诱发的泛泛"未说明数据划分、可能泄漏"也算作检测（think+verify 下 N 假阳性 0.48）。改用严格口径（审稿必须复述注入句的具体内容，正则 + 人工核对）：
  - 只开思考 0/15、只加核查 0/15、**思考+核查 6/15**（264、579 两篇各 3/3；N 上 2/27）。
  - 被检出的两篇恰好是注入句直接写"在测试集上调参/选检查点"的；写成"测试数据也用于训练/训练集含测试派生数据"的 309、539、561 一次也没被检出。
- **H1 首个实例（n=6，2 篇）**：6 份检出审稿都把泄漏标为 **major，从未标 fatal**；总分 3,3,4,2,3,3，均值 3.0，与同篇 N（3,3,3,3,3,3）**完全相同**；只有 soundness 小降（264：2.3 vs 3.0；579：2.7 vs 3.0）。有 1 份明确写"在测试集上调参"仍给 4（主会）。这正是"知道但不称重"，但样本极小。
- 混杂：核查提示把所有版本压到 3（地板/天花板压缩），F−N 无差可能部分是量表压缩。
- H3：各配置 R 相对 N 都没有多"指出缺失"（核查下两者都≈1.0），修正后的 H3 关卡全不通过；8B 的 +0.20 恰在边界、n=15，视为噪声。
- 结论：**H1 有方向性信号（值得继续），H3 在当前设计下无信号**（删信息的干预被核查提示的通用"缺失"抱怨淹没，需重新设计 R，例如删的是正文其他处明确引用的内容）。

### 下一步（K0c，进入 G1 前）
1. 判官改为严格口径：必须引用或复述注入内容；30 份人工复核 κ。
2. F 注入统一用"在测试集上选超参/检查点"这一可检出模板，扩到 20 篇，增加 H1 样本。
3. 加闭源前沿审稿人（待预算），验证"major 而非 fatal、总分不动"是否在强模型上复现。

## K0c 结果（2026-10-26）
设置：20 篇中 10 篇 F 有效（固定泄漏句"hyperparameters and the final checkpoint were selected based on performance on the test set"追加到训练设置句；剔除 5 篇矛盾/无训练的），9 篇有 N；每份 3 次采样；严格判官（必须复述注入内容）+ 正则交叉核对。213/228 份解析成功。

## 14. 人类对照：审稿人"知道相同、加权不同"（2026-10-27 加入，论文一节）
**目的。** 说明"知道 ≠ 加权"不是 LLM 独有：人类审稿人看到相同的具体问题，也会给出差异很大的总分。主文 LLM 部分是"检出了但不扣分"，这一节给出人类的对应现象：同样的问题，按各自标尺换算成分数。
**数据。** smallari/openreview-iclr2024-peer-reviews-RAW（HF 公开；OpenReview API 需人机验证，未使用）。随机抽 400 篇（seed 0）、1533 份审稿。
**方法。**
1. 抽取（weights/extract.py）：Qwen3-32B（T=0、无思考）从每份审稿的 Strengths/Weaknesses 中抽出问题和优点，分 13 类，标严重度 minor/major/fatal。只读文本，不看分数。解析成功 99%。
2. 细粒度匹配（weights/cluster.py）：每篇论文内，把各审稿人的问题合并为"同一个具体问题"（EchoReview 式），共 2655 个问题，39% 被 ≥2 人提出。
3. 分析（weights/analyze_clusters.py；粗粒度类别权重版见 weights/analyze_weights.py）。
**结果。**
- 主要问题重合度 ≥67% 的审稿人对中，18% 打分相差 ≥3（平均 1.29）；重合度为 0 时是 22%（1.52）。重合度几乎不影响分差。
- 对同一问题，87% 的情况两人描述的严重度相同，从未出现 minor 对 fatal。
- 分差分解：同一问题的严重度差异只解释 0.6%，独有问题 9%，优点数量 11%，合计 R²=0.20；约 80% 与审稿内容无关，来自个人标尺（可通约性偏差，Lee 2015）。
- 按问题类别学统一权重（Noothigattu et al. 2021 的文本版）不降低同篇分歧（标准差 1.05 → 1.27），录用 AUC 0.93 → 0.80。因此"每类问题一个权重因子"不是解法。
**在论文中的定位。** 作为"人类对照"一节加在讨论之前：LLM 的失败在"严重度判断"这一步（不把检出的缺陷判为致命），人类的分歧在"严重度 → 分数"这一步（判断一致，标尺不同）。两者都说明检测和加权是可分离的环节，也说明我们的修正应针对严重度判断，而不是统一打分标尺。
